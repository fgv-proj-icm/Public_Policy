# Guia de download — Bibliografia central de política judiciária

Arquivos incluídos:

1. `guia_download_bibliografia_politica_judiciaria.xlsx`
   - Planilha organizada com resumo, lista de downloads, alertas de metadados e script local.

2. `manifesto_download_politica_judiciaria.csv`
   - Manifesto tabular com DOI, URL de acesso, URL de PDF candidato, status e nome de arquivo sugerido.

3. `baixar_abertos_politica_judiciaria.py`
   - Script Python para tentar baixar apenas os PDFs abertos ou candidatos listados no manifesto.

## Observações importantes

- Foram mantidos apenas links legais ou páginas oficiais.
- Itens com acesso institucional/restrito não são baixados pelo script.
- Alguns sites, como SciELO, Cambridge, Taylor & Francis e ScienceDirect, podem bloquear automação. Nesses casos, use o URL de acesso e baixe manualmente.
- Foram identificados alertas de metadados:
  - DOI correto de Ng (2011): 10.18352/ulr.149
  - DOI correto de Staats, Bowler & Hiskey (2005): 10.1111/j.1548-2456.2005.tb00329.x
  - Autoria correta de Controlling the Courts: Visser, Schouteten & Dikkers (2019)
